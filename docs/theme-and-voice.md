## オーナー意図（確定寄り）

**個人（言い方の注意）**  
専門職の知識を使って自力で飛躍し、全国のライバルと切磋琢磨できるアプリ。  
※「（環境に）恵まれなくても」は**対外では使わない**。才能・環境への皮肉に聞こえるため。

**チーム（本丸・差別化必須）**  
怪我を防ぐ／目が行き届かなくても専門トレ、だけでは**競合に埋もれる**。  
「日誌だけ」「動画だけ」「怪我管理だけ」ではない、**記録・防ぐ・専門トレ・指導のやりとりを同じチーム環境で回す**こと、指導者席やチーム専用の閉じた運用など、**一体であること／現場の運用**で差を出す。

**ビジネス上の顔**  
- **本丸（ブランド・信頼の顔）**: チーム  
- **稼ぐ手段（収益の入口）**: 個人  
→ トップはチーム主・個人も明確（主従あり）

**旧サイトへの不服**  
素人っぽい／つなぎ弱い／遷移弱い／CTAと訴求が届かない

## テーマ（改訂）

### やめた表現
- 「環境を、**つくれるようにする**」→ 「できるようにする」感が引っかかるため不採用
- 「化ける」→ 対外では使わない。**飛躍** などに言い換え

### 全体テーマ（候補・近しい順）

1. **恵まれなくても、届く専門の知。**（個人の核が強い）  
2. **指導の手が届く、チームの環境。**（チーム本丸が強い）  
3. **専門の知が届く環境を。**（短く、チームにも個人にも使える）  
4. **続く現場に、専門の知を届ける。**  

推奨（本丸＝チーム＋個人も説明できる）:  
**「専門の知が届く環境を。」**

※「つくる／つくれる」を主語にしすぎない。**届く／防ぐ／手が回る／飛躍**で語る。

### 柱（言い換え後）

| | 社内ラベル | 対外で埋もれない核（案） |
|--|--|--|
| チーム（本丸） | 同じ環境で回す | 防ぐ・専門トレ・記録・やりとりを**ばらばらのツールにしない**。チーム専用で回す |
| 個人（収益） | 飛躍と切磋琢磨 | 専門の知を自分のペースで。**全国のライバルと切磋琢磨**（「恵まれない」は言わない） |

### チーム — 埋もれる言い方 vs 差が出る言い方

**埋もれる（避ける主訴求）**  
- 怪我を防げます  
- 目が行き届かなくてもトレーニングできます  
→ どのチーム管理・動画サービスでも言える

**差が出る（主に出す）**  
1. **記録・予防・専門トレ・指導のやりとりを、一つのチーム環境で回す**  
2. **ばらばらのノート・LINE・動画アプリにしない**  
3. **指導者席など、現場の“窓口”まで含めた運用**（機能名より先に「誰宛かがはっきりする」）  
4. その結果として、怪我を防ぎやすく、専門トレにも取り組める  

「防ぐ」は残すが、**先頭の差別化コピーにはしない**。ベネフィットの一段目に置く。

### 個人 — 皮肉にならない言い方

**避ける**  
- 環境に恵まれなくても  
- 才能に恵まれなくても  
→ 上から目線／皮肉に聞こえる

**使う（案）**  
1. 専門職の知識を、自分のペースで。全国のライバルと切磋琢磨。  
2. 自主トレで飛躍する。同世代と競える場所がある。  
3. （ストア整合）自主トレで鍛えて、同世代と競おう。  
4. 一人でも、専門の知に触れながら続けれられる自主トレ。  

「自力」は残してよい。「恵まれない」は対外NG。

## 言葉の正（キャッチ候補）

### 会社・トップ
主従: **チームが顔、個人は稼ぐ入口として併記**

候補:
1. 専門の知が届く環境を。  
2. 指導の手が届く、チームの環境から。  
3. 防ぐ・届ける・続く。チームと個人の ++Station。  

サブ（個人への橋）:
- 個人は、環境に恵まれなくても飛躍できるアプリへ。

### チーム向け（本丸）— 差別化先頭

1. 記録も、予防も、専門トレも、ばらばらにしない。  
2. ノートとLINEと動画アプリを、チームの一つの環境に。  
3. 指導の窓口まで含めて、チーム専用で回す。  

**その次の段（ベネフィット）**  
怪我を防ぎやすくし、目が行き届きにくいときでも専門的なトレーニングに取り組める。

主CTA: **チーム導入の相談**

### 個人向け（収益）— 皮肉なし

1. 専門職の知識を、自分のペースで。全国のライバルと切磋琢磨。  
2. 自主トレで飛躍する。同世代と競える場所がある。  
3. （ストア補助）自主トレで鍛えて、同世代と競おう。  

主CTA: **無料ではじめる** / ストア

## トップの顔（合意）

```
ヒーロー（チーム本丸の一文）
  → 短い個人への橋（稼ぐ手段・入口）
  → NEWS
  → 二本柱（チーム大／個人も明確だが一段小さくてよい）
```

- チームを隠さない（本丸）  
- 個人を隅にやりすぎない（収益）  
- ただし「同じ強さの二本柱」ではなく **主＝チーム、副＝個人**

## 使う / 使わない

**使う**  
届く、防ぐ（チームでは二段目）、環境、自力、飛躍、切磋琢磨、専門職、知識、手が回る、同じ環境で回す、ばらばらにしない、続く、まとめる、全国のライバル／同世代  

**使わない**  
科学的、エビデンス、データドリブン、化ける、つくれるようにする、**恵まれなくても**、今すぐ試す、革命、必ず強くなる、診断・完治  
チーム主訴求としての「怪我管理できます」「動画が見放題」単体  

**次に確認**  
1. チーム先頭は「ばらばらにしない／一つのチーム環境で回す」系で近いか？  
2. 個人は「自分のペースで＋全国と切磋琢磨」で皮肉は消えたか？  
3. 「飛躍」は残すか、もっと平常な「伸びる」にするか？
