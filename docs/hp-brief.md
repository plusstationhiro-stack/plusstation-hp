# ++Station 公式サイト brief

株式会社 Plus Station の公式サイト（`plusstation-hp`）の設計正。  
サービス理解の参照元: `plusstation-new`（個人アプリ）、`plusstation.team-support-fresh`（チーム）。

最終更新: 2026-08-20

関連: 旧HP整理・SEO/AEO設計図は **`docs/hp-redesign-blueprint.md`**（実装前の設計WIP）。

---

## 1. サイトの位置づけ

- **会社サイトとして二本柱**（個人アプリ ++Station ／ チーム向け Plus Station Team）
- 技術: 静的 HTML/CSS（必要なら薄い JS）。重いフレームワークは入れない
- Studio 審査中の利用規約・プライバシー URL は触らない（完成後にドメイン切替を検討）
- アプリ本体（`plusstation-new`）や Team Web のコードは、このリポジトリでは触らない

## 2. サービス概要（参照まとめ）

| | 個人（++Station） | チーム（Plus Station Team） |
|--|--|--|
| 誰向け | 自主トレを続けたい個人 | チーム・学校などの契約団体 |

## 6. サイトマップと各ページのゴール（IA）

方針: **トップは分岐だけ。詳細はすべて別ページ。**

```
トップ (/)
├── 個人向け（++Station）     … 機能・料金・ストア CTA
├── チーム向け（Team）         … できること概要・コンテンツ力・Googleフォームへ
├── 会社概要                   … 運営会社（別ページ必須）
├── プライバシーポリシー       … plusstation-new 流用
├── 利用規約（EULA）           … 同上
├── 特定商取引法に基づく表記   … 同上
└── パスワード再設定           … 既存のまま
```

| ページ | ゴール |
|--------|--------|
| トップ | チーム優先の信頼＋二本柱分岐。ニュースは上部 |
| 個人向け | 理解してストアへ |
| チーム向け | 「何ができるか」理解 → Googleフォーム |
| 会社概要 | 法人としての信頼の補完 |
| 法的 3 点 | 正確な文言を読める（勝手に改変しない） |
| PW 再設定 | 既存フローを維持 |

初回公開の必須ページ: 上記すべて（料金は個人向けページ内でも可。別ページにする場合はサイトマップに明示して追加）。

## 7. トップの構成順（AIDMA 寄り）

1. **ヒーロー（チーム寄り）**  
   「強いチームと組む会社」という印象（固有名詞なし）。ブランドは大きく。個人キャッチで主役を取らない。
2. **ニュース枠（予約）**  
   契約発表後に載せる枠のみ用意。**現時点では非表示または「準備中」**。千葉ジェッツ名は載せない。
3. **会社の一言・信頼**  
   運営会社としての短い説明。
4. **二本柱の分岐のみ**  
   「チーム向け」「個人向け」への入口。概要・機能・DL の詳細は書かない。
5. **フッター**  
   法的リンク、会社名、必要ならストアリンク。

## 9. 法的コンテンツ

- プライバシーポリシー・利用規約（EULA）・特商法表記は **`plusstation-new` の既存文言を流用**
- HP 側で独自に書き換えない（更新が必要ならアプリ側の正と揃えてから反映）
- Studio 審査中 URL は触らない

参照の目安（アプリ側）:

- 特商法: `plusstation-new` の subscription-legal 等
- 規約・プライバシー: `plusstation-new` の constants / FAQ 周辺

## 10. ビジュアル方針（暫定）

- 参照: 個人アプリは漆黒＋ネオン緑、Team も同系統ブランド色
- 公式サイトは会社サイトとして信頼感を優先。アプリ UI のコピーではなく、写真・実在感・余白で雰囲気を作る
- トップは承認済みのグラフィカルなヒーローを使用し、背景写真は必須としない
- 詳細は実装前にデザイン方向を別途確定してよい（この brief が構成の正）
