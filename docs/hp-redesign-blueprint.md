## 0. 一言で言うと

旧HP（Studio）は「写真＋大きなオレンジボタン」中心で、**マーケティング導線・SEO・信頼（E-E-A-T）・会社サイトとしての二本柱**が弱い。  
新サイトは **会社サイト（チーム優先＋個人）** として作り直し、見た目のプロ感と同時に **検索（SEO）／AI回答（AEO）／専門性（E-E-A-T）** を設計に埋め込む。

参照ドメイン（旧）: `orchid418137.studio.site`（トップ／`/2` 個人サービス／`/2-1` チーム支援 など）

### 2.2 旧コピー・訴求の棚卸し（使える素材）

**ヒーロー系**
- 「"新しい自分"を切り拓け」＋ ++Station
- 「トップレベルの身体能力を手に入れる」

**NEWS（公開実績・使える）**

- トレーニング・コンディショニング両面でサポート

**個人向け**
- 1人に1台 専門トレーナーを
- スピード、ジャンプ、アジリティ、筋力など身体能力を高めるオンライン自主訓練
- 専門的なトレーニング動画が見放題
- 約500種類／500本以上
- 2画面でわかりやすい（前後・側面など）
- 豊富な専門的トレーニングメニュー（上半身／下半身／体幹／ケトルベル／チューブ／ハードル／スプリント／ジャンプ／メディシンボール／ラダー／階段／坂道／ストレッチ／テーピング／フォームローラー 等）
- コンディショニング動画も見放題（ケガ予防・復帰）
- 理学療法士が効果的な方法を抜粋して配信
- 専門職による指導（顔写真あり）
- 希望するコーチによる指導も随時募集／有名コーチの練習も体験できるかも

**チーム向け**
- 選手が個々にあった自主練習を指導したいけど手が回らない
- 以前のサービスは機能不足・使い勝手が悪い
- コーチ作成メニューを動画でまとめて／各自で取り組めるようサポート
- 故障選手向け・A/B/Cチーム別・遠征組向けなど要望に対応
- コーチ不在時は有資格者がメニュー提案
- オンラインで疲労・コンディション管理、遠征・自宅でも動画メニュー

**会社**
- 私たちについて → 代表挨拶／経営理念／経営方針（カード3枚）
- SNSセクションあり（中身はスクショでは途中）

**CTA（旧・乱発）**
- 個人向けアプリを試す（オレンジ）
- 今すぐ試してみる（オレンジ）
- チーム支援について（緑）
- 個人向けサービスについて（緑）
- ご希望のメニューが作成可能か聞いてみる（緑）

### 2.3 旧HPの問題点（マーケティング／SEO視点）

1. **CTAが多すぎてゴールが不明**（個人試す／今すぐ／チームについてが同列）
2. **会社／個人／チームのIAが混在**（トップに個人CTAが先、優先度と不一致）
3. **見出しが感情コピー中心**で検索意図・キーワードと弱い
4. **写真上の文字が多く、SEO/AEOに弱い**（画像OCR依存）
5. **専門性（資格名・経歴本文）が弱い**（顔はあってもテキストで弱い）
6. **構造化データなし**（Studio想定）
7. **NAP・会社情報の一貫性が弱い**（特商法・会社概要との接続が薄い）
8. **素人感**: 緑枠だらけ、ボタン巨大、余白・タイポ不足、Studioバッジ
9. **被リンク設計がない**（パートナーは載せるだけで終わり）

### 2.4 新サイトへ「持っていくもの」

| 持っていく | 捨てる／作り直す |
|------------|------------------|
| 4色パレット | Studio構造そのもの |
| CHEVAL提携NEWS（公開可） | 千葉ジェッツ表記（未発表） |
| 500本級動画・カテゴリ一覧の中身 | CTA乱発 |
| 指導者の悩みコピー | 「有名コーチ体験できるかも」等の煽りすぎ |
| 専門職の顔写真・監修事実 | 画像の上だけの説明文 |
| チーム向けメニュー柔軟性（故障／A B C／遠征） | 感情ヒーローをメインH1にする方針 |

### 4.2 タイトル / H1 のルール

各ページで **1つの主キーワード** を決める。

- meta description: 課題→提供→CTAを120字前後
- 画像alt: 装飾以外は内容を日本語で記述（「画像1」禁止）

## 5. AEO（AI回答最適化）設計

AI（ChatGPT / Perplexity / Google AI Overview 等）が抜き出しやすい形にする。

### 5.1 書くルール

1. **結論先出し**の短い段落（2〜3文）を各ページ先頭に置く  
   例: 「Plus Station Team は、スポーツチーム向けに体調管理・自主トレ動画・記録をまとめるサービスです。」
2. **FAQブロック**をチーム／個人に設置（質問文＝ユーザーが聞く言い回し）
3. **定義文**を1か所に固定（「++Stationとは」「Plus Station Teamとは」）
4. 箇条書きで機能を列挙（AIがリスト抽出しやすい）
5. 数値は出典・条件付きで（「動画500本以上」など）— 誇張禁止、更新日を書く

### 5.2 想定されるAIへの質問（先に答えを用意）

- ++Station / Plus Station とは何ですか？
- 個人アプリとチーム向けの違いは？
- 料金は？（個人＝公開価格／チーム＝個別見積）
- どんなチームが使える？
- 誰がコンテンツを作っている？（資格・監修）
- 導入実績は？

### 5.3 構造化データ（Schema）予定

| タイプ | 置き場 |
|--------|--------|
| `Organization` | 全ページ共通（JSON-LD） |
| `WebSite` + `SearchAction`（任意） | トップ |
| `SoftwareApplication` | 個人ページ |
| `Service` または `Product` | チームページ |
| `FAQPage` | チーム／個人のFAQ |
| `Person`（代表・監修者） | 会社 or 専門性セクション |
| `NewsArticle` / `Article` | 実績・NEWS各記事 |
| `BreadcrumbList` | 下層ページ |
