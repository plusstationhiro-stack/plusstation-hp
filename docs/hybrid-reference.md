# 参考ハイブリッド案 — TeamSnap ONE × Squadline → ++Station

更新: 2026-08-20  
方針: **型と導線は盗む。抽象キャッチ（all-in-one／ばらばらにしない）は盗まない。**  
中身の言葉はオーナーの現場語（防ぐ／専門トレ／飛躍／切磋琢磨）で埋める。

---

## お互いのいいところ（抽出）

### TeamSnap ONE から取る

| いいところ | 具体 |
|------------|------|
| **B2Bの主CTA** | FVに「Request a demo / Chat with sales」＝重いが明確。購入ではなく**会話の入口** |
| **誰の一日かで機能を切る** | 登録→試合当日、コーチ／家族など**役割ストーリー** |
| **信頼ブロックが太い** | Trusted by…／クラブの声／導入の安心（サポート） |
| **価格はカスタム** | 「合わせます」＋デモへ（Plus Stationの個別契約と相性◎） |
| **FAQが厚い** | 乗り換え・サポート・何か、を先回り |

### Squadline から取る

| いいところ | 具体 |
|------------|------|
| **日常語の見出し** | “Never miss a practice.” など**映像が浮かぶ短文**（抽象スローガンじゃない） |
| **数字の社会証明** | チーム数・選手数・評価（※Plusは捏造しない。公開できるものだけ） |
| **Before → After** | 「旧: LINE＋Sheets…／新: 一つ」を**具体物の名前**で並べる（概念語にしない） |
| **役割別（Coach / Parent / Club）** | 読む人が自分を選べる |
| **見た目・余白・モダンさ** | 旧Studioの素人感の反面教師。余白と1カラムの気持ちよさ |
| **個人寄りの軽いCTA** | Free / Get started（＝Plusのストア・無料開始と対応） |

### 両方から**取らない**こと

- 「ONE platform」「all-in-one」をヒーローの主役にする（腐る・AIっぽい・競合と同質）
- CTAをページ内で違う意味に散らかす
- 機能カタログの羅列だけで終わる

### トップ（会社）ハイブリッド構成

1. **FV（TeamSnap型）**  
   - 誰向けか一言（クラブ／指導者）  
   - 主CTA: 「導入の相談」or「デモを見る」  
   - 副: 「個人アプリを見る」  
2. **信頼（TeamSnap型）**  
   - シュバル等の実績（ロゴ＋1行）  
3. **二本の入口（主従つき）**  
   - チーム大／個人はやや小さく但し明確  
4. フッター  

※抽象キャッチは置かない。FVは「誰に何をする会社か」＋ボタン。

### チームページ `/team`（本丸）— TeamSnap骨格 × Squadline語感

| # | セクション | 型の出典 | Plus で埋める中身（例・現場語） |

| 1 | FV | TeamSnap | 指導者・クラブ向け。CTA「導入の相談／デモ」 |
| 2 | 数字 or 実績 | Squadline | 公開できるものだけ（シュバル、後から増やす） |
| 3 | 課題（日常語） | Squadline | 例: 「朝の体調、誰が未提出か分からない」「怪我の兆しを後から知る」※抽象禁止 |
| 4 | 解決を役割で | TeamSnap | 指導者／選手／運営のそれぞれで「何が楽になるか」 |
| 5 | 具体シーン見出し×3〜4 | Squadline | 例見出し案（要ブラッシュ）: 「怪我を、後追いしない」「メニューが選手の手元に届く」「日誌の窓口がはっきりする」 |
| 6 | Before→After | Squadline | 旧: 紙・LINE・感覚 ／ 新: 体調・防ぐ・専門トレ・やりとり（**道具の名前で書く**） |
| 7 | 専門職 | 自社 | ヒロ／クロ |
| 8 | 声・実績 | TeamSnap | 取れる範囲で。無ければシュバル記事へ |
| 9 | 利用の流れ | TeamSnap | 相談→契約→招待→定着 |
| 10 | 価格 | TeamSnap | 個別見積＋相談CTA（金額断定しない） |
| 11 | FAQ | 両方 | 個人課金との違い、データ分離、デモ有無 |
| 12 | 最終CTA | TeamSnap | 同じ主CTAを再掲 |

**主CTA文言候補（TeamSnap寄せ）**  
- 「デモを見る」  
- 「導入の相談をする」  
※「お問い合わせ」より行動が具体。

**副CTA**  
- 「導入実績を見る」（シュバル）  
- 「個人アプリを見る」

## コピーのルール（ハイブリッド後）

1. 見出しは **Squadline式**: 短く、現場のシーンが浮かぶ  
2. CTAは **TeamSnap式**: デモ／相談が主、温度の違う副を1つ  
3. 「一つにまとめる」は**見出しにしない**。必要なら Before/After の表の中だけで具体物を並べる  
4. 科学・エビデンス・恵まれない・化ける・ばらばらにしない … NG継続

ハイブリッド構成は **OK（2026-08-20）**。

#### 不採用メモ
- ~~怪我を、後から知るのをやめる。~~ → 根本（早めに捉えて防ぐ）は同じだが、**ちゃちい／キャッチーすぎ**
- ~~メニューが、選手のスマホに届く。~~ → 方向は良いが、**「届く」は実態とズレる（嘘になる）**ので不使用

#### 採用（2026-08-21 オーナー決定）

| 役割 | 文言 |
|------|------|
| 系統1（防ぐ・調子） | **選手の調子を感覚で判断しない。** |
| 系統2（専門トレ） | **選手が、専門メニューに一人でも取り組める。**（2a） |
| 主CTA | **導入の相談をする** |
| チーム訴求追加 | 機能制限可 → チームに合わせたオリジナル支援プランをカスタマイズできる。料金は非公開（人数による） |
| ログイン | LPに載せない |
| 動画 | 対外「500本以上」（実数526） |
| ストア | 当面作らない |
| ヒーロー | プレースホルダ → 後で写真購入 |
