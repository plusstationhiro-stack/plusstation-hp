## 参考にする「型」（業界横断の勝ちパターン）

BtoB SaaSでリードが取れるLPの共通型:

1. **FV（最初の画面）**: 誰向け・何の会社か・主CTA（1つ）が3秒で分かる  
2. **課題**: 相手の言葉で困りごと（抽象スローガン禁止）  
3. **解決**: 画面・具体シーンで見せる（言葉だけにしない）  
4. **信頼**: 実績ロゴ／人数／導入例（シュバル等）  
5. **CTAの温度差**: 重い「問い合わせ」だけにしない（資料・デモ・相談など）  
6. **同じCTAを縦に繰り返す**（ページ内で迷わせない）

※「all-in-one」「ばらばらを一つに」は海外スポーツ管理でも使い古し。Plus Stationは**そのまま真似しない**（埋も＋AIっぽさの原因）。

## 具体的な参考候補（一緒に見る用）

### チーム（本丸）向け — B2B / スポーツ運営

| サイト | 見るポイント |
|--------|----------------|
| [TeamSnap ONE](https://www.teamsnap.com/one) | FVの主従、機能の見せ方、CTAの置き方（登録〜運営のストーリー） |
| [Squadline](https://squadline.com/) | 課題の言い方（親・コーチの日常）、モバイル前提のUX |
| 日本のBtoB SaaS LP事例まとめ（[lp-web.com BtoB特集](https://lp-web.com/blog/btob-lp/)） | 配色・資料請求／デモの二段CTA・導入ロゴの置き方 |

### 個人（収益）向け — アプリDL

| 型 | 見るポイント |
|----|----------------|
| 強いアプリLP一般 | FVにストアボタン1組、ベネフィット3つ、社会的証明 |
| 自社ストア文 | 「自主トレで鍛えて、同世代と競おう」をサイト側の補助に使う |

### CTA設計の正解例（型だけ）

主CTAを1つ決める:
- チーム: **デモを見る / 導入の相談をする**（「お問い合わせ」より行動が具体）
- 個人: **無料ではじめる（App Store / Google Play）**

副CTA（軽い）:
- 実績を見る（シュバル記事）
- 個人アプリを見る（チームLPから）
